# OpsisNewsCrawler — FAQ / Συχνές ερωτήσεις

**Focus / Αντικείμενο:** News, markets and weather / Ειδήσεις, αγορές και καιρός

## Where do I download it? / Πού το κατεβάζω;

[Latest stable published release](https://github.com/gs-applabs/OpsisNewsCrawler/releases/latest). Select the official installer and matching SHA-256 file if provided. Read the requirements, limitations and upgrade notes. A hash is an integrity check, not a signature or proof of safety. Do not bypass OS warnings.

## How do I get started? / Πώς ξεκινάω;

Read feed and plugin compatibility guidance; begin with the standalone ticker.

## What are the limitations? / Ποιοι είναι οι περιορισμοί;

Analytics are heuristic aids, not fact-checking or investment advice. Feed availability depends on the provider. / Οι αναλύσεις είναι βοηθήματα και όχι επαλήθευση ειδήσεων ή επενδυτική συμβουλή.

## Where do I find screenshots? / Πού βρίσκω εικόνες;

[Actual Windows CI screenshot gallery](product-snapshots/README.md). Some views use demonstration data. Visual tests are not full functional acceptance tests.

## Can I report a bug or suggest a feature? / Μπορώ να αναφέρω σφάλμα ή να προτείνω δυνατότητα;

[Open an issue](https://github.com/gs-applabs/OpsisNewsCrawler/issues/new/choose). Include your app and Windows versions and steps to reproduce. Redact personal data, credentials and confidential files.

## What is planned? / Τι σχεδιάζεται;

Expanded demonstrations of ticker views and analytics; provider failure handling and accessibility.

This is a non-binding direction, not a promised release date. / Ενδεικτική κατεύθυνση, χωρίς δεσμευτική ημερομηνία.
